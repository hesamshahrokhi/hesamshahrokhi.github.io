Email GitHub Google Scholar LinkedIn

Writing working code is the easy half. Now even AI can do it.

The other half is performance, reliability, safety, security, and more. Performance has been my focus in recent years — from a Ph.D. on compilation to production systems, with one method throughout: compile the workload rather than interpret it. The same approach runs through relational queries, Python dataframes, linear algebra, market data, and PDE solvers. That work continues. Alongside it, a new question: what tooling does an AI agent need to clear the other half?

/ Projects

  • PyTond

    open-source

    Automated translation of Pandas and NumPy workloads into optimized SQL, with support for sparse and dense data layouts.

  • VecHT

    open-source

    A hardware-conscious vectorized hash table in C++, offering efficient batch lookups through multi-threading, prefetching, and SIMD.

  • sdqlpy

    open-source

    The first compiled query engine embedded in Python, generating optimized C++ for analytical queries.

  • Compiled Tick-Engine

    in development

    A compiler-based engine for financial market tick data, exposing a Polars-like Python DSL and generating optimized execution code.

  • Differentiable CFD Compiler

    in development

    Lowers a Python DSL for fluid simulation to compiled C++ and differentiates the solver itself, so exact design gradients come out alongside the simulation.

  • Query-as-a-Service Platform

    in development

    A compiler-based OLAP query-processing platform with multi-frontend and multi-storage-format support.
